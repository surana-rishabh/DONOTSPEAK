# Short playable demo

1. Clock in and answer. Explain that the unknown caller might be an impostor; indirect descriptions avoid teaching dangerous concepts.
2. Type or hold-to-speak: Go to the red mark. Wait for arrival at A.
3. Release the barrier, then Proceed. All three steps are required; an early Proceed cannot clear the level.
4. Next call: Go to B → Activate the station → Verify.
5. Inspect C, then Contain or Trust from the breathing/repetition clue. Holding call: reach D → Wait → Seal the area.
6. New shift in Hindi: लाल निशान तक जाओ → रुकावट हटाओ → आगे. Hinglish works too.
7. Show orbit/reset, movable captions, Layout panel swap, and Plain view.
8. Optionally demonstrate unsafe vocabulary with Open the red door. It teaches concepts, but is not a remote shortcut or automatic forced loss.

No silence countdown, automatically enabled mic, or identity-disclosure script. Typed input/local rules keep the demo playable during outages. Health indicators show configuration only; run live smoke before presenting.
